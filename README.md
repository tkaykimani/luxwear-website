
# LUXWEAR - Thrifted Bags Website

## About the Project
Luxwear is a simple online shopping website created for a thrifted bags business based in Nairobi, Kenya.

The website allows customers to explore available handbags, learn about the business and contact the seller through WhatsApp, phone calls and Instagram.

**Tagline:** SLEEK THRIFTS TO ELEVATE YOUR LOOK.

## Features
- Homepage introducing the business.
- Shop page displaying available handbags.
- About page describing the business.
- Contact page with WhatsApp and mobile contact options.
- Instagram integration.
- Responsive website layout.

## Technologies Used
- HTML
- CSS
- PHP
- XAMPP

## Project Structure
- index.php - Homepage
- shop.php - Product collection
- about.php - About the business
- contact.php - Contact information
- css/ - Website styling
- images/ - Product photographs

## How to Run the Project
1. Install XAMPP.
2. Copy the Luxwear project folder into the htdocs directory.
3. Start Apache using the XAMPP Control Panel.
4. Open your browser.
5. Visit http://localhost/luxwear/
